Privacy Policy

ssh-analytics · Effective 6 October 2026 (previous version: 4 October 2026)

ssh-analytics is a private tool used only by its developer to read statistics for the developer's own YouTube channels and to fill in the details of videos the developer has uploaded to those channels. This policy explains what data it accesses and how that data is handled.

Data the tool accesses

After the channel owner signs in with Google and grants read-only access, the tool reads:

  • Channel and video details from the YouTube Data API (scope youtube.readonly): titles, IDs, publish dates and public counts.
  • Analytics reports from the YouTube Analytics and Reporting APIs (scope yt-analytics.readonly): views, watch time, impressions and click-through rate.

For the optional publishing feature, the owner separately grants the scope youtube.force-ssl. With it, and only when the owner runs the command and confirms the changes it shows, the tool updates videos the owner has already uploaded in YouTube Studio: title, description, tags, language, the "altered or synthetic content" and "not made for kids" settings, the scheduled publish time, a subtitle (caption) file and a thumbnail. The content it writes comes from the owner's own files on the owner's computer.

The tool never uploads videos, never deletes videos, comments or other content, and never acts on channels the owner does not own: before every update it checks that the signed-in account is the expected channel. It does not request access to email, contacts, files or any other Google data.

How the data is used

The data is used only to produce performance reports for the channel owner's own channels and to apply the video details the owner has prepared. It is not used for advertising, it is not sold, and it is not shared with or transferred to any third party.

Storage

OAuth tokens and the downloaded statistics are stored only on the channel owner's own computers. The token that allows updates is kept separately from the read-only tokens, outside any synced or shared folder. They are not uploaded to any server operated by the developer or by anyone else. A local record of which videos were updated (video ID, time, scheduled publish time) is kept alongside the owner's project files.

Retention and deletion

Report data is kept as long as the owner needs it for comparing channel performance over time, and the owner can delete it at any time by removing the local files. Access can be revoked at any time at myaccount.google.com/permissions, which makes the stored tokens stop working.

Google API Services User Data Policy

ssh-analytics's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also follows the YouTube API Services Terms of Service and the Google Privacy Policy.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
